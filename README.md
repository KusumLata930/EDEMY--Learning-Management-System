# 🎓 EDEMY - Learning Management System (LMS)

EDEMY is a full-stack Learning Management System (LMS) that enables users to explore, purchase, and access online courses. The platform is being developed with modern web technologies to provide a seamless learning experience for both students and educators.

> 🚧 **Project Status:** Currently under development. More features and improvements will be added soon.

---

## 🚀 Features

- 🔐 User Authentication
- 👨‍🎓 Student Dashboard
- 👨‍🏫 Instructor Dashboard
- 📚 Browse Available Courses
- 🎥 Course Content Management
- 💳 Course Purchase Integration
- 📈 Progress Tracking
- 📱 Responsive User Interface

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/KusumLata930/EDEMY--Learning-Management-System.git
```

### 2. Navigate to Project

```bash
cd EDEMY--Learning-Management-System
```

### 3. Install Dependencies

#### Client

```bash
cd client
npm install
```

#### Server

```bash
cd ../server
npm install
```

### 4. Configure Environment Variables

Create a `.env` file inside the **server** directory and add the required environment variables.

Example:

```env
MONGODB_URI=your_mongodb_uri
JWT_SECRET=your_jwt_secret
CLERK_SECRET_KEY=your_clerk_secret
CLOUDINARY_CLOUD_NAME=your_cloud_name
CLOUDINARY_API_KEY=your_api_key
CLOUDINARY_API_SECRET=your_api_secret
```

---

## ▶️ Run the Project

### Start Backend

```bash
cd server
npm run server
```

### Start Frontend

```bash
cd client
npm run dev
```
